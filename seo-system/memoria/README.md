# Memoria Semanal del Proyecto SEO

Esta carpeta es la **memoria de trabajo** del plan de 6 meses. Cada semana tiene un archivo
`AAAA-MM-Sx.md` (ej.: `2026-06-S2.md` = segunda semana de junio 2026) creado a partir de
`PLANTILLA_SEMANAL.md`.

## Cómo se usa

1. **Al iniciar una sesión de trabajo:** la IA lee el archivo de la semana más reciente
   (+ `../PROMPT_MAESTRO.md`) para retomar contexto: qué se hizo, qué quedó pendiente,
   qué resultados hubo.
2. **Durante la semana:** se van marcando tareas y registrando publicaciones.
3. **Al cerrar la semana (viernes):** se completa la sección de resultados, aprendizajes
   y se crea el archivo de la semana siguiente con las próximas acciones.
